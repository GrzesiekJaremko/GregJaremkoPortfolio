## About This Project

This is the codebase behind my personal portfolio site:

- **Static site** built with HTML5, SCSS, and vanilla JavaScript  
- Fully **responsive design** — optimized for desktop, tablet, and mobile  
- Hosted on GitHub Pages (`grzesiekjaremko.github.io`)  
- Clean semantic structure and **BEM-style CSS** for maintainability  
- No build tools or frameworks: lightweight & easy to extend

---

## Features

-  **Responsive layout** with mobile-first SCSS  
-  **Smooth scroll** with JavaScript for section navigation  
-  **Accessible** markup (ARIA labels, alt attributes, skip links)  
-  **Secure and fast**: no external dependencies or build processes  
-  **SEO‑friendly**: semantic headings, meta descriptions, clean URLs
